# علامة | تحدي المعرفة 🐥
## برنامج المسابقات المدرسية التفاعلية للمدارس المصرية
### الصف الثالث الإعدادي — مادة الدراسات الاجتماعية — الفصل الدراسي الأول (2026–2027)

---

### نظرة عامة
«علامة | تحدي المعرفة» هو تطبيق مسابقات تعليمية تفاعلي متكامل، مصمم خصيصاً لمدارس جمهورية مصر العربية، ليعمل **دون اتصال بالإنترنت تماماً (100% Offline)** على أنظمة Windows 10 و Windows 11، مع إمكانية نسخه وتشغيله مباشرة من فلاشة USB في الفصول الدراسية وأجهزة العرض (Data Show).

---

### مواصفات المشروع الأساسية
- **اللغة**: العربية الفصحى.
- **اتجاه الواجهة**: RTL كامل (من اليمين إلى اليسار).
- **المنهج المستهدف**: الصف الثالث الإعدادي، مادة الدراسات الاجتماعية، الفصل الدراسي الأول.
- **موضوع البداية**: الدرس الأول من الوحدة الثانية («السلالات البشرية في العالم») مع تغطية كاملة لوحدات الجغرافيا والتاريخ للترم الأول.
- **الشخصية الكرتونية**: «كتكوت علامة» 🐥 مع مؤثرات بصرية وقفز واحتفالات متحركة للمسابقات.
- **الصوت**: محرك صوتي توليدي متقدم مبني على Web Audio API (يعمل بدون ملفات خارجية أو شبكة).

---

### أنماط اللعب
1. **لاعب واحد (تحدٍّ فردي)**: للمراجعة الفردية والتدريب الذاتي مع الاحتفاظ بالاسم المخصص (مثل «يوسف»).
2. **فريقان متنافسان**: النمط الأساسي للفصل المدرسي (الفريق أ ضد الفريق ب) مع تناوب الأدوار.
3. **متعدد الفرق (3 أو 4 فرق)**: لدعم مجموعات العمل والمنافسات الجماعية الكبرى.

---

### قواعد الأدوار والنقاط
- **الإجابة الصحيحة**: +10 نقاط (قابلة للتعديل من الإعدادات)، ويظل الدور مع الفريق نفسه للسؤال التالي.
- **الإجابة الخاطئة**: 0 نقاط (مع خيار خصم إضافي اختياري)، وينتقل الدور إلى الفريق المنافس.
- **انتهاء الوقت**: 0 نقاط، وينتقل الدور إلى الفريق الآخر مع مؤثر كرتوني كوميدي.
- **تثبيت الإجابة**: قفل فوري يمنع التكرار أو تعدد النقرات.

---

### شخصية الكتكوت والمؤثرات
- **عند الإجابة الصحيحة**: قفز الكتاكيت واحتفال النجوم والقصاصات الملونة (Confetti) مع رسائل تشجيعية وعزف نغمات النصر.
- **عند الإجابة الخاطئة**: رد فعل كرتوني كوميدي (دوار لطيف وغير دموي) مع مؤثر صوتي هزلي وإظهار الشرح النموذجي ومرجع الكتاب.
- **عند انتهاء الوقت**: تعبير كرتوني مع ساعة دوارة.
- **عند الفوز**: منصة التتويج، سرب الكتاكيت الراقصة، ومؤثرات الاحتفال الكبرى.

---

### إدارة بنك الأسئلة والتقارير
- إضافة، تعديل، وحذف الأسئلة مع فحص التكرار.
- استيراد وتصدير بنك الأسئلة كملف JSON.
- سجل الجولات السابقة مع ميزة الطباعة والتصدير إلى Excel/CSV.
- توليد حزمة فلاشة USB المجهزة بملف تشغيل سريع بنقرة واحدة (`شغل_المسابقة.bat`).

---

### تشغيل الاختبارات الآلية
```bash
npm test
```
يتحقق الاختبار الآلي من:
1. اختيار 10، 20، و 30 سؤالاً عشوائياً.
2. عدم تكرار السؤال داخل الجولة.
3. دقة حساب النقاط ومنع الاحتساب المزدوج.
4. انتقال واستمرار الأدوار في نمط الفريقين.
5. إعلان الفائز وحالات التعادل.
6. الأمان والعمل التام دون إنترنت واستعادة البيانات التالفة.
